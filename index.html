       MATHEMATICAL FOUNDATIONS
      
                    

                        Understand the Algorithms
                    

                    

                        Mathematical formulation, correctness, complexity and limitations.
                    

                

                

                    

                        Problem formulation
                    

                    

                        Let C[i][j] be the estimated time for ambulance i to reach incident j. Define binary x[i][j] = 1 when ambulance i serves incident j.
                    

                    

                        Minimize Σᵢ Σⱼ C[i][j] · x[i][j]
                    

                    

                        Subject to Σⱼ x[i][j] = 1 for every ambulance i; Σᵢ x[i][j] = 1 for every incident j; and x[i][j] ∈ {0, 1}.
                    

                

                

                    

                        

                            Why Greedy can fail
                        

                        

                            With matrix [[1, 2], [2, 100]], row-order Greedy chooses 1 + 100 = 101. The cross assignment costs 2 + 2 = 4. A local minimum is not necessarily a global minimum.
                        

                    

                    

                        

                            Why DP is exact
                        

                        

                            A mask uniquely identifies assigned incidents. For the next ambulance, every unused incident is considered. Only the cheapest cost to each mask must be retained, because future choices depend only on that mask.
                        

                    

                    

                        

                            Why B&B is exact
                        

                        

                            For each remaining ambulance, take its cheapest currently available incident as an optimistic estimate. This sum may reuse an incident, so it never exceeds the true remaining assignment cost. Pruning against an incumbent cannot discard a better solution.
                        

                    

                    

                        

                            Scope and limitations
                        

                        

                            This is a static, one-to-one minimum-sum assignment simulator. It does not model clinical urgency, ambulance qualifications, traffic changes or maximum individual response time. It is not suitable for real dispatch decisions.
